# PaiTiew — ระบบจองทัวร์

ระบบสำหรับบริษัททัวร์: หน้าเว็บให้ลูกค้าค้นหาและจองทัวร์ เห็นที่นั่งว่างจริงของทุกรอบ ชำระมัดจำหรือเต็มจำนวนออนไลน์ และหลังบ้านสำหรับจัดการรอบเดินทาง ที่นั่ง รายชื่อผู้เดินทาง และการชำระเงิน

> ทำตาม [มาตรฐานการพัฒนาเว็บ](../../docs/ENGINEERING-STANDARD.md) — ข้อกำหนดเฉพาะของโปรเจกต์นี้อยู่ในภาคผนวก A.5

## Responsive (§15.2)

ทุก design เขียนแบบ mobile-first และผ่านการตรวจอัตโนมัติที่ 320 / 390 / 768 / 1024 / 1440px: ไม่มี scroll แนวนอน, พื้นที่แตะ ≥ 44px, ตัวอักษรใน input ≥ 16px, hover อยู่ใน `@media (hover: hover)` และรองรับ reduced motion

| ขนาดจอ | เมนู | การจอง | อื่น ๆ |
|---|---|---|---|
| มือถือ (< 768px) | hamburger → drawer | แถบราคา + ปุ่มจองติดล่างจอ (Horizon, Journey) · ถาดเปรียบเทียบลอยด้านล่าง (Getaway) | ปฏิทินราคาเป็นแถบวันเลื่อนแนวนอน, ตารางรอบเดินทางและรายชื่อผู้เดินทางเปลี่ยนเป็นการ์ด, หน้าต่างเปรียบเทียบเป็น sheet จากด้านล่าง |
| แท็บเล็ต (768–1023px) | hamburger → drawer | เหมือนมือถือ | ปฏิทินเต็มเดือน, ตารางแสดงครบทุกคอลัมน์ |
| เดสก์ท็อป (≥ 1024px) | เมนูเต็ม | กล่องจองติดด้านขวาขณะเลื่อน (Horizon, Journey) · ปฏิทินติดด้านซ้าย รายการรอบด้านขวา (Getaway) | แผนที่เส้นทางติดด้านซ้ายขณะอ่านกำหนดการ (Journey) |

อุปกรณ์หลัก: ลูกค้าใช้มือถือก่อน (ส่วนใหญ่กดลิงก์จาก Facebook และ LINE), ฝ่ายขาย/แอดมินใช้เดสก์ท็อป, ไกด์ใช้มือถือดูรายชื่อผู้เดินทาง

## ขอบเขตระบบ

- **หน้าสาธารณะ (SEO สำคัญ):** ค้นหา/กรองทัวร์ (ปลายทาง, เดือน, ประเภท, งบ), หน้าโปรแกรมทัวร์ (กำหนดการรายวัน, รวม/ไม่รวม, รีวิวจากผู้ที่เดินทางจริง), ปฏิทินราคา, เปรียบเทียบทัวร์
- **การจอง:** เลือกรอบ → ล็อกที่นั่งชั่วคราวระหว่างชำระเงิน → ข้อมูลผู้เดินทาง → ชำระมัดจำหรือเต็มจำนวน (PromptPay, บัตร) → ใบยืนยันทาง LINE/อีเมล, ชำระส่วนที่เหลือตามกำหนด, ลงชื่อรอเมื่อรอบเต็ม
- **ลูกค้า:** การจองของฉัน, ชำระส่วนที่เหลือ, ส่งข้อมูลพาสปอร์ต (ทัวร์ต่างประเทศ), รับแจ้งเตือนก่อนเดินทาง
- **หลังบ้าน:** จัดการโปรแกรมทัวร์และรอบเดินทาง (ความจุ, จำนวนขั้นต่ำที่ออกเดินทาง, ราคาผู้ใหญ่/เด็ก/ห้องเดี่ยว, โปรโมชัน), รายชื่อผู้เดินทาง, ตรวจสลิป, ยืนยันหรือยกเลิกรอบ, คืนเงิน, รายงานยอดขาย
- **กรุ๊ปส่วนตัว:** ฟอร์มขอใบเสนอราคา → ฝ่ายขายติดตามต่อในหลังบ้าน

กฎธุรกิจที่เห็นใน design (มัดจำ ฿2,000/คน หรือ 30%, ชำระส่วนที่เหลือก่อนเดินทาง 14–30 วัน, ล็อกที่นั่ง 15 นาที, ขั้นต่ำ 8 คน, ขั้นการคืนเงิน) เป็นค่าตัวอย่าง ระบบจริงต้องตั้งได้ต่อโปรแกรมทัวร์
