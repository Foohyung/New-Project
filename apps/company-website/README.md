# SiteSabai — เว็บไซต์บริษัทสำเร็จรูป

เว็บไซต์สำหรับแนะนำบริษัทและแสดงรายละเอียดสินค้า ให้ลูกค้าเข้ามาดูข้อมูลและติดต่อสอบถามได้ ไม่มีระบบสั่งซื้อออนไลน์ เจ้าของเว็บเพิ่มหรือแก้ไขสินค้าเองได้ผ่านหลังบ้าน

> ทำตาม [มาตรฐานการพัฒนาเว็บ](../../docs/ENGINEERING-STANDARD.md) — ข้อกำหนดเฉพาะของโปรเจกต์นี้อยู่ในภาคผนวก A.4

## สถานะ

🎨 **ขั้นเลือก design** — เลือก 1 จาก 3 แบบใน [`designs/`](designs) แต่ละแบบใช้บริษัทสมมติคนละอุตสาหกรรม เพื่อให้เห็นว่าเทมเพลตเดียวปรับใช้ได้หลายธุรกิจ

| แบบ | ไฟล์ | บริษัทตัวอย่าง | แนวทาง |
|---|---|---|---|
| 1 | [`designs/design-1-corporate.html`](designs/design-1-corporate.html) | นภาวัสดุ (วัสดุอุตสาหกรรม, B2B) | Navy + ฟ้า, น่าเชื่อถือ, ปุ่มขอใบเสนอราคา |
| 2 | [`designs/design-2-showcase.html`](designs/design-2-showcase.html) | ไร่ใบเตย ฟู้ดส์ (ของฝาก/อาหารแปรรูป) | โทนอบอุ่น, ภาพสินค้าใหญ่, สอบถามทาง LINE |
| 3 | [`designs/design-3-modern.html`](designs/design-3-modern.html) | Lumen Lighting (โคมไฟ) | Minimal, bento grid, ตัวอย่างหน้าหลังบ้าน |

## ขอบเขตระบบ

- **หน้าเว็บ:** หน้าแรก, เกี่ยวกับเรา, สินค้า (หมวดหมู่ + หน้ารายละเอียด), ข่าวสาร/บทความ, ติดต่อเรา
- **ติดต่อ:** ฟอร์มติดต่อ/ขอใบเสนอราคา (แจ้งเข้า LINE และอีเมล), ปุ่มลอย LINE OA · Messenger · โทร, แผนที่
- **หลังบ้าน (CMS):** เพิ่ม แก้ ลบสินค้า, อัปโหลดรูป, จัดหมวดหมู่, แก้แบนเนอร์และเนื้อหาหน้าเว็บ, ดูข้อความจากลูกค้า
- **SEO:** metadata, sitemap, JSON-LD `Organization` และ `Product`
- **รองรับมือถือ** ทุกหน้า
