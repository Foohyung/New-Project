## หน้าเว็บ (ระยะที่ 1)

```bash
pnpm --filter @app/dormitory dev   # http://localhost:3002
```

| หน้า | path | ทำอะไรได้ |
|---|---|---|
| ภาพรวม | `/?floor=` | อัตราเก็บเงินเดือนนี้, สถิติห้อง, ผังห้องแยกตามชั้น, งานวันนี้, รับชำระล่าสุด |
| ห้องทั้งหมด | `/rooms?status=` | กรองตามสถานะห้อง |
| ใบแจ้งหนี้ | `/bills?status=` | กรองตามสถานะบิล: การ์ดบนมือถือ / ตารางบนจอใหญ่ |
| รายละเอียดห้อง | `/rooms/[no]` | ใบแจ้งหนี้แยกรายการ, ผู้เช่า (เบอร์แบบ mask), เลขมิเตอร์ — ห้องที่ไม่มีอยู่ตอบ 404 |
| health | `/api/health` | liveness check |

การคิดบิลอยู่ใน `src/features/billing/service.ts`: ค่าไฟ ฿8/หน่วย, ค่าน้ำ ฿18/หน่วย (ขั้นต่ำ ฿100), ค่าส่วนกลาง ฿300 และรองรับมิเตอร์วนรอบ (เช่นห้อง 207) เงินทุกจำนวนเก็บเป็นสตางค์

**Test:** unit ของการคิดบิลและมิเตอร์วนรอบ และ DAL ที่กันผู้เช่าดูห้องคนอื่น (IDOR) · E2E ของผังห้อง การกรองบิล หน้าห้อง และ 404 ที่ขนาดมือถือ / แท็บเล็ต / เดสก์ท็อป

## Responsive (§15.2)

ผ่านการตรวจอัตโนมัติที่ 320 / 390 / 768 / 1024 / 1440px: ไม่มี scroll แนวนอน, พื้นที่แตะ ≥ 44px, ตัวอักษรใน input ≥ 16px, hover อยู่ใน `@media (hover: hover)` และรองรับ reduced motion

| ขนาดจอ | เมนู | ผังห้อง |
|---|---|---|
| มือถือ (< 768px) | bottom tab bar | การ์ดห้อง 2 คอลัมน์ แยกตามชั้น |
| แท็บเล็ต (768–1180px) | เมนูเป็นแถวที่สองใต้ header | การ์ดห้อง 4 คอลัมน์ |
| เดสก์ท็อป (> 1180px) | เมนูเต็มในแถวเดียว | การ์ดห้อง 4 คอลัมน์ + แผงงานวันนี้ด้านข้าง |

อุปกรณ์หลัก: ผู้เช่าใช้มือถือผ่าน LINE, เจ้าของใช้มือถือและเดสก์ท็อป, ช่างและคนจดมิเตอร์ใช้มือถือมือเดียว

## ขอบเขตระบบ

- **ห้องพัก:** ผังห้องรายชั้น, สถานะ (ว่าง / มีผู้เช่า / ค้างชำระ / ซ่อม), ประเภทห้องและราคา
- **ผู้เช่า & สัญญา:** ข้อมูลผู้เช่า (เข้ารหัสเลขบัตรประชาชน), สัญญา, เงินประกัน, ย้ายเข้า-ออก
- **บิลรายเดือน:** บันทึกมิเตอร์น้ำ/ไฟ → ออกบิลอัตโนมัติ → ส่งทาง LINE OA → PromptPay QR + ตรวจสลิป
- **แจ้งซ่อม:** ผู้เช่าแจ้ง → มอบหมายช่าง → ติดตามสถานะ
- **รายงาน:** อัตราการเข้าพัก, รายได้, ยอดค้างชำระ
