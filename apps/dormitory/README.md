# DormDee — ระบบจัดการหอพัก

ระบบจัดการหอพัก/อพาร์ตเมนต์: ห้องพัก ผู้เช่า สัญญา บันทึกมิเตอร์ ออกบิลรายเดือน รับชำระ และแจ้งซ่อม พร้อมหน้าสำหรับผู้เช่า

> ทำตาม [มาตรฐานการพัฒนาเว็บ](../../docs/ENGINEERING-STANDARD.md) — ข้อกำหนดเฉพาะของโปรเจกต์นี้อยู่ในภาคผนวก A.2

| 3 | [`designs/design-3-nightshift.html`](designs/design-3-nightshift.html) | Navy + ส้มอำพัน, ข้อมูลแน่น, มีมุมมองผู้เช่าบนมือถือ |

## Responsive (§15.2)

ทุก design ผ่านการตรวจอัตโนมัติที่ 320 / 390 / 768 / 1024 / 1440px: ไม่มี scroll แนวนอน, พื้นที่แตะ ≥ 44px, ตัวอักษรใน input ≥ 16px, hover อยู่ใน `@media (hover: hover)` และรองรับ reduced motion

| ขนาดจอ | เมนู | อื่น ๆ |
|---|---|---|
| มือถือ (< 768px) | bottom tab bar ทุกแบบ | ตารางซ่อนคอลัมน์รอง, แตะห้องในผังเพื่อดูสถานะ (ไม่ต้อง hover) |
| แท็บเล็ต (768–1023px) | Paper: sidebar ไอคอน · Garden: เมนูเป็นแถวที่สอง · Nightshift: rail มีป้ายชื่อ | ตาราง scroll ในกล่องและคอลัมน์แรก sticky, heatmap ห้องเลื่อนได้ ช่องละ 44px |
| เดสก์ท็อป (≥ 1024px) | เมนูเต็ม | — |

อุปกรณ์หลัก: ผู้เช่าใช้มือถือผ่าน LINE, เจ้าของใช้มือถือและเดสก์ท็อป, ช่างและคนจดมิเตอร์ใช้มือถือมือเดียว

## ขอบเขตระบบ

- **ห้องพัก:** ผังห้องรายชั้น, สถานะ (ว่าง / มีผู้เช่า / ค้างชำระ / ซ่อม), ประเภทห้องและราคา
- **ผู้เช่า & สัญญา:** ข้อมูลผู้เช่า (เข้ารหัสเลขบัตรประชาชน), สัญญา, เงินประกัน, ย้ายเข้า-ออก
- **บิลรายเดือน:** บันทึกมิเตอร์น้ำ/ไฟ → ออกบิลอัตโนมัติ → ส่งทาง LINE OA → PromptPay QR + ตรวจสลิป
- **แจ้งซ่อม:** ผู้เช่าแจ้ง → มอบหมายช่าง → ติดตามสถานะ
- **รายงาน:** อัตราการเข้าพัก, รายได้, ยอดค้างชำระ
