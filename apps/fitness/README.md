# FitFlow — ระบบจัดการฟิตเนส

ระบบหลังบ้านสำหรับฟิตเนส: จัดการสมาชิก แพ็กเกจ การเช็กอิน ตารางคลาส เทรนเนอร์ และการชำระเงิน พร้อมหน้าสำหรับสมาชิก

> ทำตาม [มาตรฐานการพัฒนาเว็บ](../../docs/ENGINEERING-STANDARD.md) — ข้อกำหนดเฉพาะของโปรเจกต์นี้อยู่ในภาคผนวก A.1

## สถานะ

✅ **Frontend + Backend ใช้งานจริง** — ข้อมูลเก็บใน **MySQL 8** ผ่าน Prisma 7 (`prisma/schema.prisma`) · บัญชีผู้ใช้ session และ audit log อยู่ในฐานข้อมูล · ถัดไป: 2FA สำหรับพนักงาน

ภาพโปรโมทจากหน้าจอเว็บจริง (PDF 1 หน้า A4 มีราคา รายเดือน / รายปี / ซื้อขาด) มี 3 สไตล์: [`showcase`](promo/FitFlow-โปรโมท-1-showcase.pdf) · [`spotlight`](promo/FitFlow-โปรโมท-2-spotlight.pdf) · [`editorial`](promo/FitFlow-โปรโมท-3-editorial.pdf)


## โครงสร้างโฟลเดอร์

`src/web` = หน้าบ้าน (Frontend) · `src/api` = หลังบ้าน (Backend) · ข้างในแบ่ง **ชนิด > เรื่อง > โฟลเดอร์ > ไฟล์** เช่น `src/web/app/dashboard/dashboard/dashboard.page.tsx`, `src/api/dal/members/members/members.dal.ts` · เส้นทาง URL ของ Next.js อยู่ที่ `app/` นอก src — รายละเอียดและกฎตั้งชื่อดูที่ [docs/STRUCTURE.md](docs/STRUCTURE.md) · รูปแบบ UI มาตรฐาน (popup ยืนยัน/แจ้งผล ปุ่มท้ายแถว ปุ่มย้อนกลับ แนบไฟล์) และข้อยกเว้นจากมาตรฐานกลางดูที่ [docs/UI.md](docs/UI.md)

## หน้าเว็บ

```bash
pnpm --filter @app/fitness dev   # http://localhost:7070
```

**ใช้โฟลเดอร์นี้เดี่ยว ๆ (ไม่ต้องมี monorepo):** โฟลเดอร์ `apps/fitness` ไม่พึ่ง package กลางแล้ว (utils/security อยู่ใน `src/api/lib`) ยกไปทั้งโฟลเดอร์ได้เลย ไม่ต้องเอา `node_modules` และ `.next` ไปด้วย ต้องมี Node 24 + pnpm 12

```bash
pnpm install && pnpm build
```

**ตารางในฐานข้อมูล:** แต่ละตารางเก็บอะไรและมีคอลัมน์อะไรบ้าง ดูที่ [docs/DATA-DICTIONARY.md](docs/DATA-DICTIONARY.md)

**ฐานข้อมูล (ครั้งแรก):** สร้างฐานข้อมูล MySQL (`CREATE DATABASE fitflow CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`) ใส่ `DATABASE_URL`, `SEED_OWNER_*` และ `SEED_ADMIN_*` ใน `.env` (ตั้งรหัสผ่านอย่างน้อย 8 ตัวอักษร) แล้วรัน

```bash
pnpm db:migrate   # สร้างตาราง (prisma/migrations) — รันซ้ำทุกครั้งที่อัปเดตโค้ด เช่น 0007 เพิ่มตาราง owner_branches, 0008 เพิ่ม active_from/active_to ของ users, 0009 เพิ่ม must_change_password, 0010 ตาราง password_reset_requests, 0012 ตาราง branches (ย้ายชื่อสาขาที่ใช้อยู่เข้าตารางให้อัตโนมัติ + ให้สิทธิ์ branches.manage กับ admin), 0013 คอร์สเรียนและขายหน้าร้าน (courses, course_enrollments, products, sales, sale_items, stock_movements + สิทธิ์ courses.manage / sales.use / products.manage), 0014 รูปสินค้า, 0015 เงื่อนไขคูปอง (terms, min_member_days, proof_required), 0016 สร้างแพ็กเกจครึ่งเดือน (15 วัน ฿700) และคูปอง STUDENT69 / 1MONTH ให้อัตโนมัติ, 0017 สีแบรนด์ค่าเริ่มต้น (#c6ff3d) → ใช้สีตามธีม, 0018 สิทธิ์ trainers.manage, 0019 สิทธิ์ access.view และ index ของ audit_logs (ประวัติการเข้าสู่ระบบ), 0020 เอา access.view ออกจากทุก role ยกเว้น admin, 0024 เก็บเวลาใน DB เป็นเวลาไทย (บวก 7 ชั่วโมงให้ข้อมูลเดิมทุกตาราง — รันครั้งเดียว), 0025 หัวใบเสร็จและรูปแบบเลขที่ใบเสร็จแยกสาขา (หน้า /payment-settings)
pnpm db:seed      # แพ็กเกจ · รอบแจ้งเตือน · บัญชีเจ้าของและ admin (รันซ้ำได้ ไม่เปลี่ยนรหัสผ่านบัญชีเดิม)
pnpm db:sample    # (ไม่บังคับ) ข้อมูลตัวอย่าง — เพิ่ม --reset เพื่อล้างทุกตารางก่อน ห้ามใช้กับฐานข้อมูลจริง
```

**Deploy:** ตั้งค่าในไฟล์ `.env` (ดู `.env.example`) แล้วรัน

```bash
pnpm install && pnpm db:migrate && pnpm build && pnpm start   # start คัดลอกไฟล์ static + อ่าน .env + รัน .next/standalone/server.js ให้เอง
```

- ค่าเริ่มต้น `PORT=7070`, `HOSTNAME=127.0.0.1` (รับเฉพาะในเครื่อง ให้ IIS/Caddy ที่มี HTTPS อยู่ด้านหน้า) — cookie เข้าสู่ระบบเป็น `secure` ต้องเข้าผ่าน https
- ทดสอบผ่าน `http://IP:7070` ก่อนมีโดเมน: ตั้ง `HOSTNAME=0.0.0.0` และ `ALLOW_HTTP=1` ใน `.env` — **ห้ามเปิดตอนใช้งานจริง**
- **แจ้งเตือนเข้า LINE OA เมื่อมีคนเข้า/ออกจากระบบ หรือส่งคำขอรีเซ็ตรหัสผ่านใหม่:** ตั้ง `LINE_CHANNEL_ACCESS_TOKEN` และ `LINE_NOTIFY_TO` ใน `.env` (วิธีหาค่าอยู่ใน `.env.example`) แล้ว restart · ข้อความล็อกอินบอกชื่อ ตำแหน่ง สาขา เวลาไทย IP และอุปกรณ์ · จำกัดบทบาทด้วย `LINE_NOTIFY_ROLES` เฉพาะแจ้งเข้า/ออกจากระบบ · คำขอรีเซ็ตแจ้งชื่อ บัญชี สาขา และเวลา เฉพาะคำขอใหม่ของบัญชีที่มีอยู่และใช้งานได้ (ไม่แจ้งซ้ำ) · ส่งหลังตอบผู้ใช้แล้ว LINE ล่ม/token ผิด login และการส่งคำขอยังใช้ได้ปกติ ดูสาเหตุได้ในหน้าต่าง `pnpm start` (ขึ้นต้น `[line-notify]`) · หมดเวลาเพราะไม่ได้ใช้งาน (idle timeout) ไม่แจ้ง · **หา user ID / group ID:** ตั้ง `LINE_CHANNEL_SECRET` และ Webhook URL `https://fitflows.site/api/line/webhook` (LINE Developers → Messaging API → เปิด Use webhook) แล้วพิมพ์ `id` ในแชทกับบอท หรือเชิญบอทเข้ากลุ่ม บอทจะตอบ ID กลับ (ตรวจลายเซ็น `x-line-signature` ทุกครั้ง · ไม่ตั้ง secret = webhook ปิด 404) · โค้ด: `app/api/line/webhook/route.ts`, `src/api/lib/notify/notify/line.ts`, `src/api/services/notify/notify/line-notify.service.ts`
- IP ในหน้าประวัติการเข้าสู่ระบบมาจาก `X-Forwarded-For` · ถ้ามี IIS ด้านหน้า ต้องติ๊ก "Preserve client IP" ของ ARR (IIS Manager → Application Request Routing Cache → Server Proxy Settings) ไม่อย่างนั้นทุกแถวจะเป็น 127.0.0.1 · เปิดเว็บจากตัวเซิร์ฟเวอร์เอง (localhost) จะได้ 127.0.0.1 หรือ ::1 เสมอ · ขึ้น "ไม่ทราบ" = IIS ส่ง header IP มาว่าง ดูค่าดิบได้ที่กล่อง "IP ของคุณตอนนี้" ในหน้า `/access-logs`
- ห้ามใช้ `pnpm dev` บน server: โหมด dev บล็อก JavaScript เมื่อเปิดผ่าน IP/โดเมน (ปุ่มกดไม่ได้)
- test ของ DAL (`src/api/test/*/*/*.dal.test.ts`) รันกับ MySQL ที่ `TEST_DATABASE_URL` เท่านั้น ไม่ตั้ง = ข้าม

**URL:** ชื่อ path และ parameter ตามมาตรฐาน — ดู [docs/URL.md](docs/URL.md) (มีตาราง URL เดิม → ใหม่ ที่ redirect ให้อัตโนมัติ)

**หน้าแรก (`/`):** ยังไม่เข้าสู่ระบบจะเห็นหน้าแนะนำระบบ (ฟีเจอร์ 3 ขั้นตอนเริ่มใช้งาน ราคาเช่าใช้รายเดือน/รายปี และซื้อขาด) มีปุ่ม "เข้าสู่ระบบ" ไปหน้า `/login` · เข้าสู่ระบบแล้วไปหน้าแรกตามตำแหน่ง (แดชบอร์ด `/dashboard`, เทรนเนอร์ `/classes`, สมาชิก `/me`) · ปุ่ม "ทักแชทสอบถาม" แสดงเมื่อตั้ง `LANDING_CHAT_URL` (ลิงก์ https เช่น Messenger/LINE OA) ใน `.env` ไม่ตั้ง = ซ่อน · หน้าแนะนำระบบให้ search engine เก็บได้ หน้าอื่นยัง noindex

**SEO / AEO / GEO (หน้าแรกเท่านั้น):** ข้อมูลทั้งหมดอยู่ที่ `src/api/services/landing/landing/landing.seo.ts` ที่เดียว (ชื่อ คำอธิบาย คีย์เวิร์ด คำถามที่พบบ่อย ราคา) · ตั้ง `APP_URL=https://fitflows.site` ใน `.env` ให้ลิงก์ canonical / sitemap / รูปแชร์ใช้โดเมนจริง (ไม่ตั้ง = fitflows.site)
- **SEO:** title/description/keywords, canonical, Open Graph + X card (`app/opengraph-image.tsx` สร้างรูป 1200×630), `/robots.txt` (`app/robots.ts` ปิดหน้าหลังเข้าสู่ระบบ), `/sitemap.xml` (`app/sitemap.ts`)
- **AEO:** หัวข้อ "คำถามที่พบบ่อย" (`#faq`) บนหน้าแรก + JSON-LD `FAQPage` ข้อความเดียวกัน ให้ Google/ผู้ช่วย AI ดึงคำตอบไปตอบได้ตรง ๆ
- **GEO:** JSON-LD `Organization` + `WebSite` + `SoftwareApplication` (ฟีเจอร์และราคา THB), `/llms.txt` (`app/llms.txt/route.ts` สรุปเว็บเป็น Markdown) และ robots.txt อนุญาต AI crawler (GPTBot, ClaudeBot, PerplexityBot ฯลฯ) อ่านหน้าสาธารณะ
- ไอคอนเว็บ: `app/icon.svg` (แท็บเบราว์เซอร์) และ `app/apple-icon.tsx` (หน้าจอโฮม iPhone สร้าง PNG 180×180 ตอน build) สีส้ม #FF8A3D เส้นขาว · ในหน้าเว็บ `FaviconSync` เปลี่ยนสีไอคอนแท็บตามธีม/สีแบรนด์อีกชั้น
- ไฟล์เหล่านี้ยกเว้นใน `proxy.ts` เพื่อไม่ให้ bot ถูกพาไปหน้า login · แก้ราคาใน `landing.service.ts` แล้ว JSON-LD / FAQ / llms.txt เปลี่ยนตามเอง

**เข้าสู่ระบบ:** กด "เข้าสู่ระบบ" ที่หน้าแรก หรือเปิด `/login` กรอกอีเมล (พนักงาน) หรือเบอร์โทร (สมาชิก) + รหัสผ่าน · บัญชีที่ใช้รหัสเริ่มต้นหรือถูกรีเซ็ตจะขึ้นขั้นที่ 2 "ตั้งรหัสผ่านใหม่" (≥ 8 ตัว) แล้วต้องเข้าสู่ระบบใหม่ · ลืมรหัสผ่านกดลิงก์ "ลืมรหัสผ่าน?" **ไม่มีให้เลือกบทบาท** ระบบรู้บทบาทจากบัญชีเองแล้วพาไปหน้าแรกของตำแหน่งนั้น ([ตารางสิทธิ์](docs/RBAC.md)) · ใส่ผิด 5 ครั้งล็อก 15 นาที · ออกจากระบบได้จากแถบด้านบน

## Responsive (§15.2)

ผ่านการตรวจอัตโนมัติที่ 320 / 390 / 768 / 1024 / 1440px: ไม่มี scroll แนวนอน, พื้นที่แตะ ≥ 44px, ตัวอักษรใน input ≥ 16px, hover อยู่ใน `@media (hover: hover)` และรองรับ reduced motion

| ขนาดจอ | เมนู |
|---|---|
| มือถือ (< 768px) | bottom tab bar |
| แท็บเล็ต (768–1023px) | sidebar แบบไอคอน |
| เดสก์ท็อป (≥ 1024px) | sidebar เต็ม |

**เมนู:** กลุ่ม "ตั้งค่า" (บัญชีผู้ใช้ · บทบาทและสิทธิ์ · สาขา · แบรนด์สาขา) อยู่ล่างสุดของเมนูเสมอ

**Animation เปลี่ยนหน้า:** แถบ wipe พร้อมชื่อหน้า ยาว 1.5 วินาที (`WIPE_MS` ใน `src/web/lib/layout/layout/layout.motion-routes.ts`) · หน้าที่จะมี animation ต้องอยู่ใน map `EXACT` ของไฟล์เดียวกัน (รวมหน้าตั้งค่าแล้ว) · ปิดอัตโนมัติเมื่อเครื่องตั้ง reduced motion

**Popup แจ้งผล:** ทุกการ**แก้ไข/ลบ/ยกเลิก**ข้อมูลมี popup ยืนยันก่อน (`ConfirmForm` · ลบใช้ปุ่มสีแดง) แล้วแสดง popup กลางจอเมื่อสำเร็จ (`showSuccess` — "แก้ไขสำเร็จ" / "ลบสำเร็จ" / "ทำรายการสำเร็จ" ค่าเริ่มต้นของ `ActionButton` ที่มี `confirm`) · การเพิ่ม/ส่งข้อมูลอื่นแสดง toast มุมจอ 3.5 วินาที (`toast()` ผูกกับ `ResultMessage`) · ฟอร์มใหม่ที่แก้/ลบข้อมูลให้ใช้ `ConfirmForm` + `ResultMessage successTitle` เสมอ

**ช่องแนบไฟล์:** ใช้ `FileDrop` (`src/web/components/ui/ui/ui.file-drop.tsx`) — กล่องลากวาง/กดเลือก พรีวิวรูป ปุ่มเปลี่ยน/เอาออก และตรวจขนาดฝั่ง client (server ยังตรวจซ้ำ)

อุปกรณ์หลัก: สมาชิกใช้มือถือ / LINE in-app browser, เคาน์เตอร์ใช้แท็บเล็ตแนวนอน, ผู้จัดการใช้เดสก์ท็อปและมือถือ

## ขอบเขตระบบ

- **สมาชิก:** สมัคร, แพ็กเกจ, ต่ออายุ, พักสมาชิก, แจ้งเตือนใกล้หมดอายุ
- **เช็กอิน:** QR code จากมือถือสมาชิก, ปฏิเสธอัตโนมัติเมื่อหมดอายุ
- **คลาส & เทรนเนอร์:** ตารางคลาส, จองที่นั่ง (จำกัดความจุ), จองเทรนเนอร์ส่วนตัว
- **คอร์สเรียน:** คอร์สหลายครั้งมีรอบเรียน สมาชิกสมัครเอง ชำระ PromptPay แล้วเจ้าหน้าที่ยืนยัน
- **ขายหน้าร้าน:** POS ขายน้ำ อาหารเสริม อุปกรณ์ พร้อมสต็อกและประวัติการรับ/ขาย/ปรับยอด
- **การเงิน:** PromptPay QR, ตัดบัตรรายเดือน (Omise), ใบเสร็จ, รายงานรายได้
- **แจ้งเตือน:** LINE OA
