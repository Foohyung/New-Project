# FitFlow — สิทธิ์ตามบทบาท (RBAC)

ตาม §10.2 และ §17 ของ[มาตรฐาน](../../../docs/ENGINEERING-STANDARD.md) · ต้นฉบับของตารางนี้อยู่ในโค้ดที่ [`src/features/auth/roles.ts`](../src/features/auth/roles.ts) ถ้าแก้สิทธิ์ต้องแก้ทั้งสองที่ให้ตรงกัน

- ทุกฟังก์ชันใน `src/server/dal/` ตรวจสิทธิ์เองก่อนอ่าน/เขียนข้อมูล (หน้าเว็บตรวจซ้ำเพื่อ UX เท่านั้น)
- สมาชิกเข้าถึงข้อมูลได้เฉพาะของตัวเอง โดยระบบใช้ `memberId` จาก session ไม่ใช่จาก URL (กัน IDOR)

**แยกหน้าที่ (separation of duties):** เคาน์เตอร์รับเงินได้แต่ยืนยันสลิปโอนเองไม่ได้ ต้องให้ผู้จัดการหรือเจ้าของยืนยัน · เคาน์เตอร์ใช้คูปองตอนรับชำระได้ (`payments.collect`) แต่สร้างคูปองเองไม่ได้ · สั่งรอบตัดบัตรได้เฉพาะ `payments.confirm`

**PDPA:** ข้อความแจ้งเตือน/การตลาดส่งเฉพาะสมาชิกที่ติ๊กยินยอมรับข่าวสาร (แยกจากความยินยอมใช้บริการ)

**บทบาทมาจากบัญชี:** ผู้ใช้เลือกบทบาทเองไม่ได้ — เข้าสู่ระบบที่ `/login` แล้วระบบอ่านบทบาทจากบัญชี (`src/server/accounts.ts`) · session เก็บฝั่ง server cookie `ff-session` มีแค่ token สุ่ม (httpOnly) · ใส่ผิด 5 ครั้งล็อก 15 นาที · **ระยะที่ 2:** ย้ายบัญชีและ session ไป Better Auth + 2FA สำหรับพนักงาน
